# მამული

ქართული სამაგიდო თამაში მეგობრებთან, „მენეჯერის" სულისკვეთებით: იყიდე ციხე-ქალაქები საქართველოს კუთხეებში, ააშენე კოშკები, ივაჭრე და გააკოტრე მეტოქეები.

**ითამაშე:** [qourum.github.io/mamuli](https://qourum.github.io/mamuli/)

- **ონლაინ, ყველა თავისი ტელეფონით.** ერთი ქმნის ოთახს და „მოწვევით" მეგობრებს ბმულს უგზავნის (ტელეფონზე გაზიარების მენიუ იხსნება, კომპიუტერზე ბმული კოპირდება). ბმული პირდაპირ ოთახში შეიყვანს; ოთხნიშნა კოდის აკრეფაც შეიძლება. 2–6 მოთამაშე; მასპინძელს ბოტების დამატებაც შეუძლია. ვინც თამაშიდან გავარდა, იმავე ბმულით თავის ადგილს უბრუნდება.
- **ბოტებთან ან ერთ ეკრანზე**, რამდენიმე ადამიანი ერთი ტელეფონით.
- **ხანგრძლივობას დაწყებისას ირჩევთ:** 20, 30 ან 40 რაუნდი (იგებს ყველაზე მდიდარი) ან ბოლომდე, სანამ ერთი არ დარჩება.
- **დაინსტალირება ბრაუზერიდანვე, აპივით.** მენიუში „დააინსტალირე": Chrome-ში, Edge-ში და Samsung-ის ბრაუზერში ბრაუზერი თვითონ გკითხავს; iPhone-ზე და iPad-ზე „გაზიარება" → Add to Home Screen; Mac-ის Safari-ში File → Add to Dock. დაინსტალირებული თამაში ბრაუზერის ზოლების გარეშე იხსნება, ახალი ვერსია თავისით მოდის, ბოტებთან კი ინტერნეტის გარეშეც მუშაობს.

## დაფა

40 უჯრა, რვა კუთხე თავისი ქალაქებით და შუაში დიდი თოვლიანი მთა, ყაზბეგის მსგავსი: ხევსურეთი (მუცო, შატილი), სვანეთი (ლატალი, უშგული, მესტია), სამეგრელო (ნოქალაქევი, რუხი, ზუგდიდი), იმერეთი (შორაპანი, გეგუთი, ქუთაისი), სამცხე (ხერთვისი, აწყური, ახალციხე), ქართლი (სურამი, უფლისციხე, მცხეთა), კახეთი (სიღნაღი, თელავი, გრემი) და თბილისი (ძველი თბილისი, ნარიყალა). ამას ემატება ოთხი ქარვასლა, წისქვილი და მარანი, ბედის გრაგნილი და საგანძური, ხარკი და ბაჟი, ზინდანი და სუფრა.

## წესები მოკლედ

- ყველა იწყებს 1500-ით. სტარტის გავლისას 200 გეძლევა.
- თავისუფალ ქალაქზე დადგომისას შეგიძლია იყიდო; სხვისაზე ქირას იხდი. მთელი კუთხე თუ შენია, ქირა ორმაგდება.
- თუ თავისუფალ ქალაქს არ იყიდი, ის აუქციონზე გადის: ფასს ყველა ასახელებს (წინაზე 10-ით მაინც მეტს), ვინც აღარ აპირებს, გადის. ბოლო ფასის მერე რამდენიმე წამში ქალაქი ყველაზე მაღალი ფასით იყიდება.
- მთელ კუთხეზე კოშკებს აშენებ თანაბრად: ერთიდან ოთხ კოშკამდე, მერე ციხე-სიმაგრე.
- ფული თუ არ გყოფნის, კოშკებს ყიდი და ქალაქებს აგირავებ; თუ მაინც ვერ იხდი, კოტრდები.
- შენს სვლაზე ნებისმიერ მოთამაშეს შეგიძლია ვაჭრობა შესთავაზო: ქალაქები, ფული, ფასკუნჯის ბუმბული.

სრული წესები თამაშშივეა (მენიუ → წესები).

## როგორ არის აწყობილი

ერთი გვერდი, ჩარჩოების გარეშე, ჩვეულებრივ JavaScript-ზე. სურათები [მეტეხიდან](https://github.com/qourum/metekhi) არის.

- `src/data.js`: დაფა, კუთხეები, ბარათები, გმირები.
- `src/themes.js`: თემები. ოთახის თემას მასპინძელი ლობიში ირჩევს: მამული ან არქიპელაგი (ცნობილი მეკობრეების განძის კუნძულები, ნამდვილი ამბებით). წესები იგივეა; თემა იძლევა უჯრების და კუთხეების სახელებს, ბარათებს, გმირებს, ეკრანის სიტყვებს და 3D სამყაროს. არქიპელაგში განძის სკივრი კითხვას სვამს: ყველა თავის ტელეფონზე პასუხობს, ვინც გახსნა, სწორ პასუხზე 100-ს იღებს, სხვები 20-ს. კუნძულებს და ხომალდებს თავისი ნამდვილი ამბავი აქვთ. (არქიპელაგი საიტზე მაშინ გამოჩნდება, როცა მისი ზღვა მზად იქნება; მანამდე `?sea` აჩვენებს.)
- `src/pictures.js`: არქიპელაგის სურათები კოდით: მეკობრეების პორტრეტები (სანამ მათი 3D პორტრეტები მოვა), ზღვა და კუნძული ბარათებზე, პატარა ხატულები.
- `src/engine.js`: წესები. მდგომარეობა ჩვეულებრივი ობიექტია, ყველა სვლა ამოწმებს, დასაშვებია თუ არა; აქვეა ბოტები.
- `src/net.js`: ოთახები. მასპინძლის მოწყობილობა თამაშის ძრავს ატარებს და ყოველი სვლის მერე მდგომარეობას ყველას უგზავნის (Supabase Realtime broadcast, `rt.js`). მასპინძელი თუ გავიდა, თამაშს შემდეგი მოთამაშე აგრძელებს; ვინც გავიდა, მის მაგივრად ბოტი თამაშობს, სანამ არ დაბრუნდება. ბოტი სვლას მაშინ აკეთებს, როცა წინა სვლა ყველა ეკრანმა აჩვენა (ყველაზე ნელს მაქსიმუმ 2.5 წამი ელოდება): ყოველი ტელეფონი მასპინძელს ეუბნება, რამდენი ნახა. აუქციონს მასპინძლის საათი ატარებს: ბოტები ფასს რიგ-რიგობით ასახელებენ, და როცა დიდხანს არავინ ასახელებს, ქალაქი იყიდება.
- `src/board3d.js`: 3D დაფა ([three.js](https://threejs.org), `vendor/three.min.js`, MIT ლიცენზია). ამოწეულ უჯრებზე წერია, რა არის: ქალაქის სახელი, ფასი, ბარათი, გადასახადი. კამერა ფიგურას მიჰყვება და დაფის მხარეზე გადადის. ღილაკით მთელ დაფას ნახავ. თამაშის დაწყებისას უჯრები ამოდის, მერე მიწა დაფიდან იზრდება და მთა ამოიზრდება, ბოლოს ყველაფერი ცოცხლდება. ყველაფერი ცოცხლობს ერთი შეიდერით: ფოთლები და ვაზი ქარში ირხევა, ტბები და მდინარეები ბრწყინავს, ჩანჩქერი ჩამოდის, მიწას ნიადაგის, ბალახისა და კლდის მარცვალი აქვს. კვამლი, ნაპერწკლები, ფოთოლცვენა და ჩანჩქერის შხეფები წერტილებია, რომლებსაც შეიდერი თვითონ ამოძრავებს (ერთი ხატვა ყველასთვის). აქლემები, ცხვრები, ნავები, მცველები, საბაგირო, ბაჟის ჯებირი, ღრუბლები და არწივები რამდენიმე ფორმის ასლებია (instancing). დაფა მენიუს დროს იქმნება, ნაწილ-ნაწილ, როცა გვერდს სხვა საქმე არ აქვს: იქვე კომპილირდება შეიდერები და ვიდეობარათზე იტვირთება სურათები, ასე რომ თამაშის დაწყება ტელეფონზეც არ ჭედავს. ჩრდილები თავიდან მხოლოდ მაშინ იხატება, როცა რამე გადაადგილდა; როცა დაფაზე მხოლოდ მისი სიცოცხლე მოძრაობს, ტელეფონი ნაკლებ კადრს ხატავს.
- `src/terrain.js`: რელიეფი. უჯრების რკალის შიგნით ერთიანი მიწაა: ყოველი ადგილი თავის ნაწილს აძლევს ფორმას (მწვერვალები ქედებით, გორები, ციცაბოკიდიანი კლდეები, მდინარის კალაპოტები, ტბები, მოსწორებული ადგილები შენობებისთვის), მეზობლები ერთმანეთში გადადიან, შუაში კი დიდი მთაა. ფერი მიწიდანვე მოდის: ბალახი სწორ ადგილას, ფენებიანი კლდე ციცაბოზე, თოვლი მაღლა, ბილიკები, ხეობები უფრო მუქი. წყალს თავისი ზედაპირი აქვს. დაფის გარშემო ქვეყანა გრძელდება: მინდვრები და ყანები, ტყიანი გორები, შორს ნისლში ჩაკარგული მთები.
- `src/models.js`: ყოველი ადგილის სცენა, კოდით, ფაილების გარეშე: ჯერ თავის მიწას აძლევს ფორმას, მერე მასზე აშენებს. სვანეთის კოშკები მთის ძირში, კახეთის ვენახები, ნარიყალა ქედზე საბაგიროთი, ხერთვისი კლდეზე ორ მდინარეს შორის, უფლისციხე... შუა მთაზე ეკლესიაა გორაზე, სვანური სოფელი, ტყე, ჩანჩქერი და ტბა. აქვეა, რა მოძრაობს ყოველ ადგილზე. კუთხესთან ორი ადგილი ერთ მიწას იყოფს, დიაგონალზე, თითოეული თავისი უჯრის მხარეს.
- `src/dice3d.js`: კამათელი. გაგორება ჯერ პატარა ფიზიკური სიმულაციით ითვლება (სიმძიმე, ხტომა, ხახუნი), მერე ჩანს. ყოველი გაგორება თავისი რიცხვიდან (seed) იწყება, რომელსაც მასპინძელი სვლასთან ერთად აგზავნის, სიმულაცია კი მხოლოდ შეკრებას, გამრავლებას, გაყოფას და ფესვს იყენებს, ასე რომ კამათელი ყველა ტელეფონზე ზუსტად ერთნაირად ფრენს და ერთ ადგილას ჩერდება. შემდეგი გაგორება წინასწარ, მცირე ნაწილებად ითვლება, ამიტომ კამათელი დაჭერისთანავე მიფრინავს. გაგორებული რიცხვი ზედა წახნაგზე კამათლის სიმეტრიით მოდის, მოძრაობა არ იცვლება.
- `src/ui.js`, `src/app.js`, `src/style.css`, `src/index.html`: ეკრანები, ყიდვის ბარათი, აუქციონი, კოშკების ფურცელი, ვაჭრობა. როცა ვინმე ყიდვაზე ფიქრობს, დანარჩენები ხედავენ, ვინ და რომელ ქალაქზე; მოთამაშეების ჩიპებთან მოკლე შენიშვნები ჩნდება: რა იყიდა, რამდენი გადაიხადა ან მიიღო, რა ფასი დაასახელა.
- `src/diag.js`: ტექნიკური ჟურნალი (მენიუ → ტექნიკური ჟურნალი). ტელეფონი იწერს შეცდომებს, ძალიან ნელ კადრებს (და რა ჩანდა მაშინ ეკრანზე), გრაფიკის დაკარგვას და დაბრუნებას, თამაშის შუაში აწყობილ შეიდერებს, კამათლის გაგორების დროს და კავშირის წყვეტას; ღილაკი ყველაფერს აკოპირებს. თუ ტელეფონმა 3D-ს გრაფიკა წაართვა, თამაში არ ჩერდება: ანიმაციები, რომლებსაც კადრები არ მოსდით, ბოლოში გადადიან, დაფა კი გრაფიკის დაბრუნებისას თავიდან იხატება.
- `src/sw.js`: ოფლაინ დამხმარე (service worker), მას `tools/build.py` ფესვში `sw.js`-ად წერს. გვერდი ქსელიდან მოდის, როცა ქსელი არის, და შენახულიდან, როცა არ არის; სურათები, three.js და შრიფტები ინახება. `manifest.webmanifest`, აიკონები და `screens/` (სურათები ინსტალაციის ფანჯრისთვის) თამაშს დაინსტალირებადს ხდის.

```sh
python3 tools/build.py              # index.html და sw.js ფესვში (GitHub Pages ამას აჩვენებს)
python3 tools/build.py --preview DIR  # გვერდი Claude-ის არტიფაქტისთვის (ონლაინ ოთახების გარეშე)
python3 tools/make_icons.py         # აიკონები და og.jpg
node tests/sim.js                   # ბოტების ასობით თამაში: წესები არ უნდა გაიჭედოს
```

`index.html` აწყობილი ფაილია: ცვლილებები `src/`-ში კეთდება და მერე `tools/build.py` ეშვება.
