# მამული

ქართული სამაგიდო თამაში მეგობრებთან, „მენეჯერის" სულისკვეთებით: იყიდე ციხე-ქალაქები საქართველოს კუთხეებში, ააშენე კოშკები, ივაჭრე და გააკოტრე მეტოქეები.

**ითამაშე:** [qourum.github.io/mamuli](https://qourum.github.io/mamuli/)

- **ონლაინ, ყველა თავისი ტელეფონით.** ერთი ქმნის ოთახს და მეგობრებს ოთხნიშნა კოდს ან ბმულს უგზავნის. 2–6 მოთამაშე; მასპინძელს ბოტების დამატებაც შეუძლია.
- **ბოტებთან ან ერთ ეკრანზე**, რამდენიმე ადამიანი ერთი ტელეფონით.
- **ხანგრძლივობას დაწყებისას ირჩევთ:** 20, 30 ან 40 რაუნდი (იგებს ყველაზე მდიდარი) ან ბოლომდე, სანამ ერთი არ დარჩება.

## დაფა

40 უჯრა, რვა კუთხე თავისი ქალაქებით: ხევსურეთი (მუცო, შატილი), სვანეთი (ლატალი, უშგული, მესტია), სამეგრელო (ნოქალაქევი, რუხი, ზუგდიდი), იმერეთი (შორაპანი, გეგუთი, ქუთაისი), სამცხე (ხერთვისი, აწყური, ახალციხე), ქართლი (სურამი, უფლისციხე, მცხეთა), კახეთი (სიღნაღი, თელავი, გრემი) და თბილისი (ძველი თბილისი, ნარიყალა). ამას ემატება ოთხი ქარვასლა, წისქვილი და მარანი, ბედის გრაგნილი და საგანძური, ხარკი და ბაჟი, ზინდანი და სუფრა.

## წესები მოკლედ

- ყველა იწყებს 1500-ით. სტარტის გავლისას 200 გეძლევა.
- თავისუფალ ქალაქზე დადგომისას შეგიძლია იყიდო; სხვისაზე ქირას იხდი. მთელი კუთხე თუ შენია, ქირა ორმაგდება.
- მთელ კუთხეზე კოშკებს აშენებ თანაბრად: ხის კოშკი, ქვის კოშკი, სამეფო, გუშაგიანი და ციხე-სიმაგრე.
- ფული თუ არ გყოფნის, კოშკებს ყიდი და ქალაქებს აგირავებ; თუ მაინც ვერ იხდი, კოტრდები.
- შენს სვლაზე ნებისმიერ მოთამაშეს შეგიძლია ვაჭრობა შესთავაზო: ქალაქები, ფული, ფასკუნჯის ბუმბული.

სრული წესები თამაშშივეა (მენიუ → წესები).

## როგორ არის აწყობილი

ერთი გვერდი, ჩარჩოების გარეშე, ჩვეულებრივ JavaScript-ზე. სურათები [მეტეხიდან](https://github.com/qourum/metekhi) არის.

- `src/data.js`: დაფა, კუთხეები, ბარათები, გმირები.
- `src/engine.js`: წესები. მდგომარეობა ჩვეულებრივი ობიექტია, ყველა სვლა ამოწმებს, დასაშვებია თუ არა; აქვეა ბოტები.
- `src/net.js`: ოთახები. მასპინძლის მოწყობილობა თამაშის ძრავს ატარებს და ყოველი სვლის მერე მდგომარეობას ყველას უგზავნის (Supabase Realtime broadcast, `rt.js`). მასპინძელი თუ გავიდა, თამაშს შემდეგი მოთამაშე აგრძელებს; ვინც გავიდა, მის მაგივრად ბოტი თამაშობს, სანამ არ დაბრუნდება.
- `src/board3d.js`: 3D დაფა ([three.js](https://threejs.org), `vendor/three.min.js`, MIT ლიცენზია). ამოწეულ უჯრებზე წერია, რა არის: ქალაქის სახელი, ფასი, ბარათი, გადასახადი. კამერა ფიგურას მიჰყვება და დაფის მხარეზე გადადის. ღილაკით მთელ დაფას ნახავ.
- `src/models.js`: ყოველი ქალაქის სცენა ყუთებისგან, კონუსებისგან და ცილინდრებისგან, ფაილების გარეშე: სვანეთის მთები და კოშკები, კახეთის ვენახები, ნარიყალა, უფლისციხის კლდე... თამაშის დაწყებისას დაფიდან ამოდის, ყიდვისას ხტება.
- `src/dice3d.js`: კამათელი. გაგორება ჯერ პატარა ფიზიკური სიმულაციით ითვლება (სიმძიმე, ხტომა, ხახუნი), მერე ჩანს. გაგორებული რიცხვი ზედა წახნაგზე კამათლის სიმეტრიით მოდის, მოძრაობა არ იცვლება.
- `src/ui.js`, `src/app.js`, `src/style.css`, `src/index.html`: ეკრანები, ყიდვის ბარათი, კოშკების ფურცელი, ვაჭრობა.

```sh
python3 tools/build.py              # index.html ფესვში (GitHub Pages ამას აჩვენებს)
python3 tools/build.py --preview DIR  # გვერდი Claude-ის არტიფაქტისთვის (ონლაინ ოთახების გარეშე)
python3 tools/make_icons.py         # აიკონები და og.jpg
node tests/sim.js                   # ბოტების ასობით თამაში: წესები არ უნდა გაიჭედოს
```

`index.html` აწყობილი ფაილია: ცვლილებები `src/`-ში კეთდება და მერე `tools/build.py` ეშვება.
